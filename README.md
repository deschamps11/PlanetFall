### 🕹️ Nasıl Oynanır?
1. `.zip` dosyasını indirin ve bir klasöre çıkartın.
2. Klasör içindeki `.exe` dosyasına çift tıklayarak oyunu başlatın.
3. Ana menüde **SPACE** tuşuna basarak oyuna girin.
4. **W, A, S, D** veya **Ok Tuşları** ile gemiyi kontrol edin.
